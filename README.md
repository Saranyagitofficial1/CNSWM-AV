Autonomous vehicles operate in dynamic and uncertain environments where understanding the intentions of surrounding agents is essential for safe decision making. Conventional deep learning methods achieve strong predictive performance but often lack causal reasoning, uncertainty awareness, and explainability.

This repository presents **CNSWM (Causal Neuro-Symbolic World Model)**, a unified framework that combines deep neural perception, causal reasoning, symbolic knowledge, and uncertainty estimation to enable reliable intent prediction and adaptive risk-aware decision making.
